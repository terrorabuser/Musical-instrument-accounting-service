# 🎸 Система учета музыкальных инструментов

Полнофункциональное веб-приложение для учета, управления и оценки стоимости музыкальных инструментов с системой авторизации и комментариев.

## 📁 Структура проекта

```
Musical-instrument-accounting-service/
├── backend/              # Java Spring Boot REST API
│   ├── src/
│   │   └── main/
│   │       ├── java/     # Исходный код приложения
│   │       └── resources/
│   │           └── db/migration/  # Flyway миграции
│   └── Dockerfile
├── frontend/             # React TypeScript SPA
│   ├── src/
│   │   ├── components/   # React компоненты
│   │   ├── contexts/     # Контексты (авторизация)
│   │   └── services/     # API сервисы
│   └── Dockerfile
├── docker-compose.yml    # Docker конфигурация
└── API_DOCUMENTATION.md  # Документация API
```

## ✨ Функциональные возможности

### 🔐 Система авторизации
- **Регистрация пользователей** — создание аккаунта с уникальным логином и никнеймом
- **Вход в систему** — авторизация с использованием JWT токенов
- **Защита маршрутов** — доступ к редактированию только для авторизованных пользователей
- **Сохранение сессии** — автоматическое восстановление сессии при перезагрузке

### 🎻 Управление инструментами
- **Добавление инструментов** — создание новых записей с детальной информацией
- **Редактирование** — обновление информации об инструментах
- **Удаление** — удаление инструментов (только владельцем)
- **Загрузка изображений** — добавление фотографий инструментов
- **Привязка к владельцу** — каждый инструмент связан с пользователем-владельцем

### 🔍 Расширенная фильтрация и поиск
- **Фильтр по типу** — гитары, клавишные, духовые, ударные и др.
- **Фильтр по бренду** — выбор производителя
- **Поиск по названию** — текстовый поиск по наименованию
- **Фильтр по цене** — указание минимальной и максимальной стоимости
- **Фильтр по дате** — фильтрация по дате добавления
- **Фильтр по состоянию** — новый, отличное, хорошее, удовлетворительное
- **Сортировка** — по цене, дате, названию (по возрастанию/убыванию)

### 💬 Система комментариев
- **Добавление комментариев** — авторизованные пользователи могут оставлять комментарии
- **Редактирование** — изменение своих комментариев
- **Удаление** — удаление своих комментариев
- **Привязка к инструменту** — комментарии относятся к конкретному инструменту

### 📊 Статистика
- **Общая стоимость** — сумма стоимости всех инструментов
- **Средняя стоимость** — среднее значение по всем инструментам
- **Количество инструментов** — общее число записей

### 📄 Пагинация
- **Постраничный вывод** — отображение по 12 инструментов на странице
- **Навигация** — переход между страницами
- **Информация о страницах** — текущая страница и общее количество

### 🎨 Интерфейс
- **Современный дизайн** — красивый и интуитивно понятный UI
- **Адаптивная верстка** — корректное отображение на разных устройствах
- **Карточки инструментов** — наглядное представление информации

## 🚀 Запуск проекта

### Требования
- **Docker** и **Docker Compose** — для запуска backend и базы данных
- **Node.js** (v18+) — для запуска frontend

### Шаг 1: Установка Node.js

1. Скачайте Node.js с официального сайта: [https://nodejs.org/](https://nodejs.org/)
2. Выберите версию **LTS** (рекомендуется)
3. Запустите установщик и следуйте инструкциям
4. Проверьте установку:
```bash
node --version
npm --version
```

### Шаг 2: Запуск Backend (Docker)

1. Убедитесь, что Docker запущен
2. В корневой папке проекта выполните:

```bash
docker-compose up --build
```

Это запустит:
- **PostgreSQL** на порту `5432`
- **Backend API** на порту `8080`

Для запуска в фоновом режиме:
```bash
docker-compose up --build -d
```

### Шаг 3: Запуск Frontend

1. Откройте новый терминал
2. Перейдите в папку frontend:
```bash
cd frontend
```

3. Установите зависимости:
```bash
npm install
```

4. Запустите сервер разработки:
```bash
npm run dev
```

Frontend будет доступен по адресу: **http://localhost:5173**

## 📡 API Endpoints

### Аутентификация
| Метод | Endpoint | Описание | Авторизация |
|-------|----------|----------|-------------|
| POST | `/api/auth/register` | Регистрация пользователя | Нет |
| POST | `/api/auth/login` | Вход в систему | Нет |

### Инструменты
| Метод | Endpoint | Описание | Авторизация |
|-------|----------|----------|-------------|
| GET | `/api/instruments` | Список инструментов (с фильтрами) | Нет |
| GET | `/api/instruments/{id}` | Получить инструмент по ID | Нет |
| POST | `/api/instruments` | Создать инструмент | Да |
| PUT | `/api/instruments/{id}` | Обновить инструмент | Да |
| DELETE | `/api/instruments/{id}` | Удалить инструмент | Да |
| GET | `/api/instruments/types` | Список всех типов | Нет |
| GET | `/api/instruments/brands` | Список всех брендов | Нет |
| GET | `/api/instruments/statistics/total-value` | Общая стоимость | Нет |
| GET | `/api/instruments/statistics/average-value` | Средняя стоимость | Нет |

### Комментарии
| Метод | Endpoint | Описание | Авторизация |
|-------|----------|----------|-------------|
| GET | `/api/comments/instrument/{id}` | Комментарии к инструменту | Нет |
| POST | `/api/comments` | Создать комментарий | Да |
| PUT | `/api/comments/{id}` | Обновить комментарий | Да |
| DELETE | `/api/comments/{id}` | Удалить комментарий | Да |

## 🗄 База данных

База данных создается автоматически через Flyway миграции:

| Миграция | Описание |
|----------|----------|
| V1 | Создание таблицы `musical_instruments` |
| V2 | Заполнение начальными данными |
| V4 | Исправление типов полей изображений |
| V5 | Создание таблицы `users` |
| V6 | Добавление владельца к инструментам |
| V7 | Создание таблицы `comments` |

### Учетные данные PostgreSQL

```
Username: instruments_user
Password: instruments_pass
```
